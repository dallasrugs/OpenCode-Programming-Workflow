# W3C source excerpt (paraphrased fixture)
Source: https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html
Retrieved: 2026-11-01. Primary publisher: W3C WAI. This page is informative guidance for WCAG 2.2 SC 1.4.3, Level AA.
Ordinary text requires at least 4.5:1 contrast. Large-scale text requires at least 3:1. Incidental text and logotypes have stated exceptions. These are contrast requirements, not a required brand palette or evidence of user aesthetic preference.
