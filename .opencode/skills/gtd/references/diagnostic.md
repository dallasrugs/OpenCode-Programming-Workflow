# GTD System Health-Check

> Load when the user wants to diagnose their own setup ("is my system actually working?", "audit my GTD", "why does my system keep falling apart?") or you want to find the weakest link. Pick the few checks that bite hardest — don't quiz all of them.

A GTD system fails at its **weakest link** (capture → clarify → organize → reflect → engage). Find the broken stage and fix *that*, not everything.

## Capture
- **Is your head actually empty?** Test: *"I absolutely know right now everything I'm not doing but could be doing."* If thoughts still nag, capture is leaking. → full mind-sweep (`02`).
- **As few buckets as possible, all trusted?** Too many capture points = none trusted. → consolidate.
- **Is capture friction near zero?** If it's not "fast, functional, and fun," they resist it. → fix the tool.

## Clarify
- **Are your next actions physical, visible single actions?** Scan their list: "Mom," "budget," "set meeting," "website" are **not** next actions — they're stuck. Each should read like "Call X re Y," "Draft Z." This is the **#1 failure point.** → re-clarify into physical verbs.
- **Is "in" processed to empty regularly** (not used as storage)? → process to zero; never put things back in "in."
- **Are sub-2-minute things being tracked instead of just done?** → apply the 2-minute rule.

## Organize
- **Projects list complete and current?** Most people have **30–100**; far fewer usually means hidden multi-step commitments living as vague single items. → surface them.
- **Does *every* project have at least one next action?** Projects without a next action are where momentum and trust leak. → add one to each.
- **Calendar = hard landscape only** (time/day-specific)? Soft "would like to" to-dos on the calendar erode trust in it. → move them to Next Actions.
- **Next Actions sorted by @context?** One giant list forces constant re-sorting and gets ignored. → split by context.
- **Waiting For list exists and is dated?** Untracked delegations = dropped balls. → build it; date every hand-off.
- **Buckets kept separate** (reference not mixed into action lists, someday not mixed into active)? → separate them "visually, physically, psychologically."
- **Is there ≥ ~50 next-actions + waiting-fors** across contexts? Far fewer usually means the inventory is incomplete (Allen's skeptic test).

## Reflect
- **Are you doing a Weekly Review?** This is *the* critical success factor — its absence is the most common reason systems decay. → install a weekly ~2-hour block (`05`).
- **Daily: calendar first, then context action lists?**

## Engage / Horizons
- **Do you have an Areas of Focus (20k) list** — the hats you wear? *"If you're not totally sure what your job is, it will always feel overwhelming."* The most commonly missing horizon. → list 4–7 professional + personal areas.
- **Choosing actions by context → time → energy → priority** (not priority-first guesswork)?
- **Runway & projects under control before reaching for vision/purpose?** If the bottom is out of control, top-down planning won't stick.

## How to run it
1. Find the **weakest link** — usually one of: capture leaking, next actions not physical, no Weekly Review, or no Areas-of-Focus list.
2. Name it, explain the cost, and prescribe the **one** highest-leverage fix (then re-check).
3. If they want the full pass, walk Capture → Engage in order and stop at the first stage that's broken — fixing an upstream stage often clears the downstream symptoms.
